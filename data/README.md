# Measurement Data

`m30.mat` contains 100 rotating-antenna measurement realizations.

```text
Variable: m30
Size:     19 x 5 x 100
Type:     double
```

Column interpretation from the source CSV files:

1. Mean angle
2. Power at 3.00 GHz
3. Power at 3.03 GHz
4. Power at 3.06 GHz
5. Relative angle

See `../docs/VALIDATION.md` before changing any frequency or BS labels.
